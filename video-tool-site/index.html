PERSONAL CONTENT PIPELINE

대본 한 줄에서 업로드까지,
영상 제작을 7단계 파이프라인으로.

video_tool은 개인이 운영하는 유튜브·틱톡 채널의 콘텐츠 제작 과정을 자동화하기 위해 만든 개인용 도구입니다. 대본 작성부터 음성·자막·이미지 생성, 장면 합성, 최종 조립, 채널 업로드까지 — 한 사람이 여러 채널을 운영할 수 있도록 제작 과정을 단계별로 자동화합니다.

ABOUT

video_tool은 채널 소유자 본인이 직접 검토한 대본만을 기반으로 영상을 제작합니다. 업로드는 각 플랫폼의 공식 OAuth 인증을 통해 본인 채널에만 연결되며, 여러 채널의 제작·업로드 현황은 구글 시트 하나로 통합 관리합니다.

모든 기능은 채널을 직접 운영하는 개인의 반복 작업을 줄이기 위해 만들어졌습니다. 각 단계는 독립적으로 동작하기 때문에, 특정 장면이나 특정 채널만 다시 처리하는 것도 가능합니다.
