음성·자막·이미지를 각각 모듈로 만든다

파싱된 데이터를 바탕으로 TTS 음성, 자막 파일, 장면 이미지를 씬 단위로 개별 생성합니다. 각 모듈은 독립적으로 재생성할 수 있어, 특정 장면만 수정할 때 전체를 다시 만들 필요가 없습니다.

CAN DO이 단계에서 할 수 있는 일

  • 씬별 음성 생성 — 로컬 TTS 엔진으로 나레이션 음성을 장면 단위로 생성합니다.
  • 타임코드 자막 — 생성된 음성 길이에 맞춰 자막 파일의 타이밍을 자동으로 계산합니다.
  • 이미지 정리 — 외부 이미지 생성 도구로 받은 장면 이미지를 씬 번호에 맞게 자동 배치합니다.
  • 부분 재생성 — 마음에 들지 않는 장면 하나만 골라 다시 생성할 수 있습니다.
